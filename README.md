# Игра в бизнес (`@_kartuzzz`)

Статическое mobile-first веб-приложение с четырьмя быстрыми инженерными расчётами для малого бизнеса: где теряются время и выручка на ручной работе и с чего начать автоматизацию. Разработано для аудитории блога [@_kartuzzz](https://www.threads.net/@_kartuzzz) в Threads.

Публичный адрес (GitHub Pages): **https://kartuznik.github.io/poket_game/**

---

## Состав инструментов (MVP)

1. **Калькулятор выручки под риском (`#revenue-risk`)** — оценка потенциальных потерь от поздних или пропущенных ответов на обращения клиентов.
2. **Калькулятор рутины (`#routine-calc`)** — подсчёт времени, уходящего на повторяющиеся операции (ответы, заказы, записи, перенос данных в таблицы).
3. **Диагностика «Что автоматизировать первым» (`#priority-diag`)** — ранжирование шести процессов по частоте, времени и цене ошибки с передачей приоритетного процесса в калькуляторы.
4. **Чек-лист готовности к автоматизации (`#readiness-check`)** — проверка девяти базовых условий готовности («рано / закрой пробелы / можно начинать»).

> **Статус (Этап 1):** Поднят каркас приложения, навигация с синхронизацией URL, три дизайн-направления на выбор владельца (`minimal`, `playful`, `editorial`), связка передачи контекста между инструментами (`ToolBridge`) и протестированные общие утилиты (`format`, `clipboard`, `storage`). Бизнес-формулы и отраслевые пресеты подключаются на Этапе 2.

## Технический стек и ограничения

- **Сборщик и язык:** `Vite` + `TypeScript` (`strict: true`, `noUncheckedIndexedAccess: true`, `exactOptionalPropertyTypes: true`).
- **UI и стили:** Чистый HTML + CSS-переменные (`src/styles/tokens.css`, `src/styles/main.css`), mobile-first, системный шрифтовой стек и инлайн-SVG (ноль внешних сетевых запросов и CDN).
- **Тестирование:** `Vitest` (юнит-тесты в `src/lib/__tests__/`).
- **Приватность:** Без backend, регистрации, трекеров и аналитики. Введённые данные не покидают браузер; поддерживается локальное сохранение сценариев «До / После» с мягкой деградацией в приватном режиме WebView.

## Структура проекта

```text
poket_game/
├── .github/workflows/
│   └── deploy.yml              # Автодеплой на GitHub Pages при пуше в main
├── index.html                  # Точка входа, OpenGraph и mobile-first мета-теги
├── package.json
├── tsconfig.json
├── vite.config.ts
├── public/
│   └── favicon.svg             # Локальная векторная иконка
└── src/
    ├── main.ts                 # Инициализация каркаса, роутинга и переключателя тем
    ├── styles/
    │   ├── tokens.css          # Дизайн-токены для 3 направлений (minimal, playful, editorial)
    │   └── main.css            # Mobile-first раскладка, доступность и адаптивная сетка
    ├── lib/
    │   ├── types.ts            # Контракты инструментов, сценариев и переходов
    │   ├── format.ts           # Форматирование рублей, процентов, времени и склонений
    │   ├── clipboard.ts        # Копирование в буфер с fallback для мобильных WebView
    │   ├── storage.ts          # Сравнение сценариев «До / После» с защитой от Private Mode
    │   ├── bridge.ts           # URL-роутер и in-memory передача результатов между инструментами
    │   └── __tests__/
    │       └── lib.test.ts     # Юнит-тесты утилит и граничных случаев
    └── tools/
        ├── catalog.ts          # Метаданные 4 инструментов и 3 дизайн-направлений
        ├── stub-factory.ts     # Каркас экрана Этапа 1 (поле ввода + карточка результата)
        ├── revenue-risk/
        │   └── view.ts
        ├── routine-calc/
        │   └── view.ts
        ├── priority-diag/
        │   └── view.ts
        └── readiness-check/
            └── view.ts
```

## Команды для локальной работы

```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера
npm run dev

# Проверка типов TypeScript
npm run typecheck

# Запуск юнит-тестов
npm test

# Продакшн-сборка в каталог dist/
npm run build

# Локальный предпросмотр собранного бандла
npm run preview
```
