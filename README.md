# Игра в бизнес (`@_kartuzzz`)

Статическое mobile-first веб-приложение: четыре расчёта про ручную работу и выручку, затем экран с подтверждёнными цифрами. Сделано для аудитории [@_kartuzzz](https://www.threads.com/@_kartuzzz) в Threads.

Публичный адрес (GitHub Pages): **https://kartuznik.github.io/poket_game/**

Бэкенда, регистрации, трекеров и внешних шрифтов нет. Черновик и подтверждённые ответы живут в `localStorage` под ключом `poket_game:dossier:v1` (версия досье `1`). Подтверждённый снимок инструмента записывается только на последнем шаге. Пустой первый заход не подставляет чужие цифры: поля пустые, кнопка «Дальше» выключена, пока шаг не заполнен. Если черновик или снимок уже есть, они восстанавливаются.

---

## Путь

1. **Калькулятор выручки под риском** (`#revenue-risk`) — 4 шага: обращения, доля поздних, конверсия, чек и доля возврата.
2. **Калькулятор рутины** (`#routine-calc`) — 4 шага: сценарий или свои цифры, операции, минуты, доля автоматизации и необязательная ставка.
3. **Диагностика «Что автоматизировать первым»** (`#priority-diag`) — 6 шагов, по одному процессу. Балл появляется только после оценок.
4. **Чек-лист готовности к автоматизации** (`#readiness-check`) — 3 шага по три пункта. «Да» / «Частично» / «Нет» не выбраны заранее.
5. **Ваш бизнес-аудит завершён** (`#audit-finish`) — итог по подтверждённым инструментам, копирование отчёта, таблица CSV и ссылка на Threads. Формы контактов нет.

Вкладка **Итоги** (`#final-report`) показывает то, что уже подтверждено, и не входит в счётчик пути.

## Выручка под риском

На экране поле называется «Какую долю этих денег можно вернуть быстрым ответом» и принимает 0–100%. Больше значение — больше денег в потенциале возврата.

В досье по-прежнему хранится `lossFactor`: доля, которую считают потерянной (`0..1`). Доля возврата на экране — это `1 - lossFactor`. Старое досье с `lossFactor: 0.3` читается как 70% возврата и не превращается в `NaN`.

Формулы:

1. Поздние обращения = обращения × доля поздних / 100.
2. Выручка под риском = поздние обращения × конверсия / 100 × средний чек.
3. Потенциал возврата = выручка под риском × доля возврата.
4. В год = выручка под риском × 12.
5. Цена одного пропущенного диалога = средний чек × конверсия / 100.

Режим **«Сценарное допущение»** подставляет один из четырёх круглых сценариев. Это не статистика по России и не замер бизнеса. Режим **«Моя конверсия»** принимает 1–95%.

| Сценарий | Конверсия | Доля возврата на экране | `lossFactor` в досье |
| --- | --- | --- | --- |
| Бьюти, здоровье, локальные услуги | 30% | 50% | 0.5 |
| Товарный бизнес | 20% | 50% | 0.5 |
| Эксперты и обучение | 12% | 58% | 0.42 |
| B2B и сложные услуги | 8% | 63% | 0.37 |

Пример, если ввести 100 обращений, 35% поздних, конверсию 20%, чек 4 500 ₽ и долю возврата 70%: риск 31 500 ₽, потенциал возврата 22 050 ₽. Сами по себе эти числа в поля не подставляются.

## Рутина, приоритет, готовность

Рутина: часы в месяц = операции в неделю × минуты × 4,33 / 60. Экономия часов = часы × доля автоматизации. Рубли считаются только если указана ставка. Ноль в ставке — это ноль рублей, а не «ставка не указана».

Приоритет: балл = частота × 0,4 + время × 0,3 + цена ошибки × 0,3, шкала 1–5. При равенстве выше процесс с более дорогой ошибкой, затем с более высокой частотой.

Готовность: «Да» = 1, «Частично» = 0,5, «Нет» = 0, максимум 9. Меньше 4 — «Рано», меньше 7 — «Закройте пробелы», 7 и выше — «Можно начинать».

## Отчёт и таблица

Текст для копирования начинается с «Игра в бизнес — отчёт для Ефима». CSV скачивается в браузере: разделитель `;`, UTF-8 с BOM, десятичная запятая, имя файла `business-game-report.csv`. Колонка выручки называется «Доля возврата, %».

## Стек

Vite, TypeScript (`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Vitest. Стили на CSS-переменных, системный шрифт, инлайн-SVG. Светлая и тёмная схема хранится отдельно от параметра `theme` в адресе: `theme` — это вариант оформления (minimal / playful / editorial), не светлая или тёмная тема.

```text
src/
├── main.ts
├── styles/
├── lib/          # досье, шаги, CSV, мост между инструментами
├── components/   # мастер шагов, тосты, конфетти, переключатель темы
└── tools/
    ├── revenue-risk/
    ├── routine-calc/
    ├── priority-diag/
    ├── readiness-check/
    ├── final-report/
    └── audit-finish/
```

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```
