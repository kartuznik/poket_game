# Игра в бизнес (`@_kartuzzz`)

Статическое mobile-first веб-приложение с четырьмя быстрыми инженерными расчётами для малого бизнеса: где теряются время и выручка на ручной работе и с чего начать автоматизацию. Разработано для аудитории блога [@_kartuzzz](https://www.threads.net/@_kartuzzz) в Threads.

Публичный адрес (GitHub Pages): **https://kartuznik.github.io/poket_game/**

---

## Состав инструментов

1. **Калькулятор выручки под риском (`#revenue-risk`) — РЕАЛИЗОВАН (Этап 2)**
   - Оценка потенциальных потерь от поздних или пропущенных ответов на обращения клиентов.
2. **Калькулятор рутины (`#routine-calc`)** — подсчёт времени, уходящего на повторяющиеся операции (ответы, заказы, записи, перенос данных в таблицы).
3. **Диагностика «Что автоматизировать первым» (`#priority-diag`)** — ранжирование шести процессов по частоте, времени и цене ошибки с передачей приоритетного процесса в калькуляторы.
4. **Чек-лист готовности к автоматизации (`#readiness-check`)** — проверка девяти базовых условий готовности («рано / закрой пробелы / можно начинать»).

## Инструмент 01: Калькулятор выручки под риском (`src/tools/revenue-risk/`)

### Математическая модель и формулы

**Входные параметры:**
- `leadsPerMonth` — количество обращений в месяц (по умолчанию `100`).
- `lateSharePercent` — доля поздних или неотвеченных обращений в процентах (`0–100%`, по умолчанию `35%`).
- `conversionPercent` — конверсия из обращения в покупку в процентах:
  - режим **«Моя конверсия»**: ручной ввод `1–95%` (по умолчанию `20%`);
  - режим **«Средняя по нише (РФ)»**: автоматическая подстановка из 4 отраслевых пресетов.
- `avgCheck` — средний чек в рублях (по умолчанию `4 500 ₽`).
- `lossFactor` — доля безвозвратных потерь на поздних ответах (`0..1`).

**Формулы расчёта:**
1. $\text{Поздние обращения в месяц} = \text{leadsPerMonth} \times \frac{\text{lateSharePercent}}{100}$
2. $\text{Выручка под риском в месяц} = \text{lateLeads} \times \frac{\text{conversionPercent}}{100} \times \text{avgCheck}$
3. $\text{Потенциал возврата при автоматизации} = \text{revenueAtRiskMax} \times (1 - \text{lossFactor})$
4. $\text{Выручка под риском в год} = \text{revenueAtRiskMax} \times 12$
5. **Триггерная метрика (цена одного пропущенного диалога):**
   $$\text{costPerMissedDialog} = \text{avgCheck} \times \frac{\text{conversionPercent}}{100}$$

### Отраслевые пресеты по рынку РФ и допущения

При выборе режима **«Средняя по нише (РФ)»** используются 4 пресета с явным дисклеймером *«Усреднённая оценка по рынку РФ, не ваши данные»*:

1. **Бьюти, здоровье, локальные услуги** (запись на приём/визит): конверсия `30%` (диапазон `25–40%`), доля потерь `0.5`.
2. **Товарный бизнес / E-commerce** (одежда, подарки, декор, цветы): конверсия `20%` (диапазон `15–25%`), доля потерь `0.5`.
3. **Эксперты, обучение, инфопродукты** (фриланс, агентства, наставничество): конверсия `12%` (диапазон `8–18%`), доля потерь `0.42`.
4. **B2B / Сложные услуги с высоким чеком** (ремонт, производство, разработка): конверсия `8%` (диапазон `5–12%`), доля потерь `0.37`.

В режиме «Моя конверсия» для расчёта потенциала возврата применяется базовый коэффициент потерь `lossFactor = 0.3` (потенциал спасения 70% выручки в зоне риска за счёт мгновенного первого ответа). Все входные данные и результаты автоматически сохраняются в `ToolBridge` (`saveRevenueRiskResult` / `send`) для передачи в другие инструменты.

## Технический стек и дизайн-система

- **Сборщик и язык:** `Vite` + `TypeScript` (`strict: true`, `noUncheckedIndexedAccess: true`, `exactOptionalPropertyTypes: true`).
- **Визуальный стиль:** Тактильные карточки с контрастным контуром `2px` и жёсткой офсетной тенью + кобальтово-индиговая палитра (`#1D4ED8`). Системный шрифтовой стек и инлайн-SVG (ноль внешних сетевых запросов и CDN).
- **Тестирование:** `Vitest` (юнит-тесты общих утилит и расчётного ядра `src/tools/revenue-risk/calc.test.ts`).
- **Приватность:** Без backend, регистрации, трекеров и аналитики.
